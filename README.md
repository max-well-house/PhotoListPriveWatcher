# PhotoList Price Watcher

Monitors photo listing prices and notifies when they change.

## Structure

```
src/
  scrapers/       # Listing page scrapers
  watchers/       # Price watch / polling logic
  models/         # Data models
  utils/          # Shared helpers
  notifications/  # Alerts (email, webhook, etc.)
config/           # App configuration
data/             # Local data / cache (not committed)
tests/            # Tests
docs/             # Documentation
```
